Evershade

A self-hosted AI agent platform built as a collection of specialized microservices. Create, manage, and run AI-powered agents on your own hardware.

v1.14.0 MIT License Docker Python TypeScript Production Ready
Get Started Explore Services

What Is Evershade

Your personal AI workforce that lives on your computer or server.

🔒

You Own Everything

Your data, your agents, your conversations – nothing leaves your machine unless you explicitly connect an external AI provider.

🐳

Runs in Docker

No complex setup. If you can run Docker, you can run Evershade. Minimal profile needs just 4 GB RAM and 2 CPU cores.

⚡

Agents Do Real Work

Write code, scrape websites, search knowledge bases, send notifications, and chain tasks together.

🎯

Mission Control

Break large tasks into milestones, let AI plan and execute, then validate automatically with fix-revalidate cycles.

🧩

Modular Architecture

Use just the core services or add observability, notifications, local LLMs – you choose what you need.

🔌

Extensible

MCP servers, custom plugins, skills system, and event-driven hooks for unlimited extensibility.

Platform Overview

10 specialized microservices, each with a single responsibility.

Speedy – CLI tool (evershade command) Optional

Quick Start

Get up and running in minutes.

git clone https://github.com/LukaG712/Evershade.git && cd Evershade

# Install service repositories (required)
./install.sh --profile minimal    # Linux/macOS
# .\install.ps1 -Profile minimal  # Windows PowerShell

cp .env.example .env
# Edit .env with your API keys

# Start services
./start.sh --profile minimal      # Linux/macOS
# .\start.ps1 -Profile minimal    # Windows PowerShell

The API will be available at http://localhost:8080.

Note: Service repositories are maintained separately and must be cloned by the install script. See the Getting Started Guide for a detailed walkthrough.

Installation Profiles

Choose the right profile for your needs.

Profile Services Command
Minimal Core only (4 services) docker compose --profile minimal up -d
Standard All services (8 services) docker compose --profile standard up -d
Full + Slammer Dashboard docker compose --profile full up -d
+ Ollama Local LLM support docker compose --profile standard --profile ollama up -d
+ Proxy Caddy reverse proxy with TLS docker compose --profile standard --profile proxy up -d

Key Features

  • ✓ Agent Management – Create, configure, and run AI-powered agents with custom guidelines
  • ✓ Mission Control – Break large tasks into milestones with automated planning, execution, and validation
  • ✓ Code Execution – Agents write and modify code in isolated Git worktrees using Junie CLI
  • ✓ Web Scraping – Playwright-based scraping, crawling, and browser automation
  • ✓ Knowledge Graph – Persistent storage with semantic search and Obsidian vault integration
  • ✓ Multi-LLM Support – OpenAI, Anthropic, Google AI, and local Ollama models
  • ✓ Observability – Metrics, distributed traces, logs, and alerting with OTLP export
  • ✓ Secrets Management – AES-256-GCM encrypted secrets with versioned configuration
  • ✓ Notifications – Slack, Discord, Email, and Telegram with templating
  • ✓ Workstations – Isolated container environments for agent execution
  • ✓ Agent Harness – Spec Mode, custom droids, skills, and event-driven hooks
  • ✓ Security – CSRF protection, rate limiting, RBAC, container hardening
  • ✓ Web Dashboard – React-based dashboard for full platform management
  • ✓ CLI Tool – Terminal-based management with evershade command
  • ✓ Backup & Restore – Automated backups with integrity verification
