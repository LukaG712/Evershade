Evershade

A self-hosted AI agent platform built as a collection of specialized microservices.

Why Evershade

Modular Microservices

10 independent services, each with a single responsibility. Mix and match via Docker Compose profiles.

AI Agent Orchestration

Create, manage, and run AI agents with pipelines, workflows, and workstations — all from one dashboard.

Multi-Provider LLM

Route requests to OpenAI, Anthropic, Google, or Ollama with cost tracking and privacy classification.

Web Scraping & Crawling

Playwright-powered scraping, deep crawling, and site mapping with Redis-backed job queues.

Encrypted Secrets

AES-256-GCM encryption for secrets at rest with versioned configuration management.

Full Observability

Metrics, distributed traces, log aggregation, and alerting with deduplication and cooldown.

Quick Start

git clone https://github.com/LukaG712/Evershade.git && cd Evershade
cp .env.example .env
# Edit .env with your API keys
docker compose --profile minimal up -d

Dashboard available at http://localhost:8080

Naming Theme

All service names are inspired by Luigi's Mansion ghosts. The root repository is named Evershade after Evershade Valley, the setting of Luigi's Mansion: Dark Moon.
