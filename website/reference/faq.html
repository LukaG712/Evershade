❓ Frequently Asked Questions

Common questions about Evershade, organized by topic.

General

What is Evershade?

Evershade is a self-hosted AI agent platform built as a collection of specialized microservices. It lets you create, manage, and run AI-powered agents on your own hardware for tasks like code generation, web scraping, research, and more.

Is Evershade free?

Yes. Evershade is open-source software licensed under the MIT License. You can use it for personal or commercial purposes without restriction.

Why the ghost theme?

All services are named after ghosts from the Luigi's Mansion series. The repository is named Evershade after Evershade Valley from Luigi's Mansion: Dark Moon. This is a fan-made project and is not affiliated with Nintendo.

What AI models does Evershade support?

Through Shrewd, Evershade supports OpenAI (GPT-4o), Anthropic (Claude), Google AI (Gemini), and local Ollama models. You can configure multiple providers with automatic fallback.

Installation

What are the minimum system requirements?

Minimum: 2 CPU cores, 4 GB RAM, 10 GB disk. Recommended: 4+ cores, 8+ GB RAM, 20+ GB disk. With Ollama: 8+ cores, 16+ GB RAM.

Do I need Docker?

Yes. Evershade runs entirely in Docker containers. You need Docker Engine 24+ or Docker Desktop.

Can I run Evershade on Windows?

Yes. Use PowerShell scripts (install.ps1, start.ps1, stop.ps1) and Docker Desktop.

Why do I need to run the install script?

Service repositories are maintained separately and must be cloned by the install script. This keeps the main repository lightweight.

Services

Which services are required?

Four core services are required: Greenie (orchestrator), Slinker (code execution), Trapper (web scraping), and Gobber (storage). All others are optional.

What happens if an optional service is unavailable?

The platform continues to operate. Greenie logs a warning and marks the service as unavailable. Features depending on that service degrade gracefully — no cascade failure.

Can I use Evershade without a web dashboard?

Yes. Greenie is API-only. Slammer (the dashboard) is optional. You can manage everything via the API or the Speedy CLI tool.

How do services communicate?

Services communicate via HTTP/JSON REST APIs for synchronous requests and Redis pub/sub for async events. All communication happens on the internal Docker network.

Security

Is my data safe?

Your data stays on your machine. Nothing leaves your hardware unless you explicitly connect an external AI provider. Secrets are encrypted at rest with AES-256-GCM.

How do I secure Evershade for production?

Enable TLS with the Caddy proxy profile, configure firewall rules, replace all default API keys, set EVERSHADE_MODE=server, and enable rate limiting.

Can I access Evershade remotely?

Yes, but you should use SSH tunneling, VPN (Tailscale/WireGuard), or the Caddy reverse proxy with TLS. Never expose services directly to the internet without proper security.

How are secrets stored?

Hider encrypts all secrets using AES-256-GCM with a 96-bit random nonce per operation. The encryption key is derived from EVERSHADE_ENCRYPTION_KEY via SHA-256.

Agents

What is an agent?

An agent is an AI-powered worker that executes tasks. Each agent has a name, a runner (Junie), and guidelines that define its behavior.

What is Mission Control?

Mission Control breaks large tasks into milestones, lets AI plan and execute, then validates automatically with fix-revalidate cycles. It's the primary way to run complex, multi-step AI workflows.

Can agents run code safely?

Yes. Slinker supports three isolation levels: worktree (shares host filesystem), container (isolated Docker container), and workstation (full VM isolation). Use container or workstation for untrusted code.

What are workstations?

Workstations are isolated Docker containers that provide a full development environment for agents. They have their own filesystem, network, and resource limits.

Troubleshooting

Services won't start. What do I do?

Run evershade doctor for diagnostics. Check docker compose logs for error messages. Verify your .env file has all required API keys.

I get "port already in use" errors.

Find the conflicting process (netstat -ano | findstr :8080 on Windows) or change the port in docker-compose.yml.

How do I reset everything?

Run docker compose down -v to stop services and delete volumes. Then reconfigure and restart. Make sure to backup first with evershade backup create.

Docker is running out of memory.

In Docker Desktop, go to Settings → Resources and increase memory to at least 8 GB. Restart Docker after changing.

How do I enable debug logging?

Set EVERSHADE_LOG_LEVEL=DEBUG in your .env file and restart services with docker compose restart.

Where can I report bugs?

Report issues on GitHub Issues. Include your .env configuration (redacted) and relevant logs.
