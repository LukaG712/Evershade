Changelog

All notable changes to the Evershade platform.

Releases

v1.12.0 – Agent Harness v1.11.0 – CSRF & OTLP v1.10.0 – Smoke Tests v1.9.0 – Mission Analytics v1.8.0 – Mission Control

v1.12.0 – Agent Harness

2026-10-22

Factory-inspired agent harness capabilities for reusable workflows, specialized subagents, and event-driven automation.

What's New

  • ✓ Spec Mode – Read-only research phase before implementation. Create specs, run repository analysis, approve/reject plans, and convert approved specs to missions.
  • ✓ Custom Droids – Specialized subagents defined in Markdown with own prompts, models, and tool policies. Built-in droids: worker, explorer, reviewer, validator.
  • ✓ Skills System – Reusable SKILL.md workflows with trigger-based auto-discovery. Skills can be matched to tasks and invoked manually.
  • ✓ Hooks System – Event-driven lifecycle hooks for mission events (PreToolUse, PostToolUse, MissionStart, MissionEnd, MilestoneComplete, ValidationFail).
  • ✓ Environments – Reusable sandbox definitions with repository, dependencies, setup commands, and health checks.
  • ✓ 30+ New API Endpoints – REST endpoints for specs, droids, skills, hooks, and environments.
  • ✓ 30 Unit Tests – Covering all five components.

v1.11.0 – CSRF Protection & OTLP Export

2026-10-22

Security hardening with CSRF protection, vector embeddings API for Gobber, and OpenTelemetry Protocol export for Sneaker.

What's New

  • ✓ CSRF Protection – Token generation with HMAC signing, validation with expiry, double-submit cookie pattern.
  • ✓ Gobber Embeddings API – Vector embedding generation, semantic search, batch processing, and statistics.
  • ✓ Sneaker OTLP Export – Receive and forward traces, metrics, and logs via OpenTelemetry Protocol.
  • ✓ 45 Unit Tests – Covering CSRF, embeddings, and OTLP components.

v1.10.0 – Integration Tests & Hardening

2026-10-22

End-to-end smoke tests, cross-service integration tests, and final hardening for production readiness.

What's New

  • ✓ E2E Smoke Tests – 8 tests covering full mission lifecycle from create to complete.
  • ✓ Cross-Service Tests – 13 tests covering API health, lifecycle, planning, validation, and analytics.
  • ✓ Dashboard Fixes – Fixed mission duration display in Slammer React dashboard.

v1.9.0 – Mission Analytics & Streaming

2026-10-22

Real-time mission analytics, SSE streaming for live logs, and automatic fix-revalidate cycles.

What's New

  • ✓ Mission Analytics – Success/failure rates, average durations, model usage tracking, validation findings.
  • ✓ SSE Streaming – Real-time mission execution logs via Server-Sent Events.
  • ✓ Fix-Revalidate Cycle – Automatically create worker features from validation failures with configurable retries.
  • ✓ Execution Logging – Logs at all lifecycle points with pagination and timestamp queries.
  • ✓ 40 Unit Tests – Covering analytics, logs, SSE, and fix-revalidate.

v1.8.0 – Mission Control System

2026-10-22

The Factory-inspired Mission Control system — orchestrated AI missions with milestones, validation, and automated execution.

What's New

  • ✓ Mission Lifecycle – Create, plan, execute, validate, complete, cancel, pause, resume with checkpoint recovery.
  • ✓ Event Automation – GitHub webhooks, schedule-based triggers with cron parsing, rate limiting.
  • ✓ Secret Redaction – Pattern-based redaction of API keys, tokens, and passwords in logs and model context.
  • ✓ LLM Planning – AI-based task planning via Shrewd with heuristic fallback and repo context.
  • ✓ Repository Intelligence – Automatic analysis of project structure, frameworks, build commands, and conventions.
  • ✓ Auto Review – Deterministic checks (test, lint, type) plus diff-based security review.
  • ✓ React Dashboard – Full-featured mission UI with list, create, detail views, and action buttons.
  • ✓ 100+ Tests – Unit, integration, and component tests covering the entire system.
