Prerequisites

  • Docker and Docker Compose
  • Junie CLI (for code agents) — optional

Installation

Evershade services live in separate repositories. After cloning, run the bootstrap script to fetch all services at compatible versions.

git clone https://github.com/LukaG712/Evershade.git && cd Evershade
cp .env.example .env
# Edit .env with your API keys (see Configuration section below)

# Bootstrap service repositories (required first time)
./install.sh          # Linux/macOS
.\install.ps1         # Windows PowerShell

# Start services
./start.sh            # Linux/macOS
.\start.ps1           # Windows PowerShell

The dashboard will be available at http://localhost:8080, and the standalone Slammer dashboard at http://localhost:5173.

Startup Scripts

Startup scripts validate configuration before starting services, supporting profiles and deployment modes.

# Linux/macOS
./start.sh              # Start with default profile (standard)
./start.sh --profile minimal   # Start core services only
./start.sh --profile full      # Start all services + dashboard
./start.sh --mode server       # Server mode (refuses default keys)
./stop.sh                 # Stop all services

# Windows PowerShell
.\start.ps1             # Start with default profile (standard)
.\start.ps1 --profile minimal
.\stop.ps1              # Stop all services

Configuration

API Keys (Required)

Generate unique keys for each service. Never use the default values in production.

# Generate a secure key
openssl rand -hex 32

All variables use the EVERSHADE_<SERVICE>_<SETTING> naming convention.

VariableDescription
EVERSHADE_GREENIE_API_KEYGreenie API key
EVERSHADE_SLINKER_API_KEYSlinker API key
EVERSHADE_TRAPPER_API_KEYTrapper API key
EVERSHADE_GOBBER_API_KEYGobber API key

Tutorial: Your First Agent

Step 1: Install and Start

git clone https://github.com/LukaG712/Evershade.git && cd Evershade
cp .env.example .env
# Edit .env — at minimum, set unique API keys

# Bootstrap service repositories
./install.sh          # Linux/macOS
.\install.ps1         # Windows PowerShell

# Start services
./start.sh            # Linux/macOS
.\start.ps1           # Windows PowerShell

Step 2: Access the Dashboard

Open http://localhost:8080 in your browser. You'll see the Greenie dashboard with:

  • Chat — Talk to AI agents
  • Dashboard — Manage agents, runs, pipelines
  • API Docs — Swagger UI at /docs

Step 3: Create Your First Agent

  1. Go to Dashboard → Agents
  2. Click Create Agent
  3. Fill in:
    • Name: researcher
    • Runner: junie
    • Guidelines: Always cite your sources.
  4. Click Save

Step 4: Run a Task

  1. Go to Chat
  2. Select your researcher agent
  3. Type: Summarize the key points of climate change
  4. Watch the agent work in real-time

Step 5: Try a Pipeline

Create a cross-service pipeline via the API:

curl -X POST http://localhost:8080/api/pipeline \
  -H "Authorization: Bearer $EVERSHADE_GREENIE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "steps": [
      { "service": "Trapper", "action": "scrape", "url": "https://news.ycombinator.com" },
      { "service": "Greenie", "action": "chat", "agent": "researcher", "prompt": "Summarize the top 5 stories" }
    ]
  }'

Step 6: Explore More

  • Workflows — Automate recurring tasks with schedules and triggers
  • Slammer Dashboard — Standalone dashboard at http://localhost:5173
  • Speedy CLI — Manage everything from the terminal: evershade agents list
  • Notifications — Configure Slack/Discord alerts via Poltergeist
  • LLM Providers — Connect OpenAI, Anthropic, or Ollama via Shrewd

Security Notes

  • Server mode refuses to start with default API keys.
  • Resource limits are applied to all services.
  • Store your .env file securely and never commit it to version control.
