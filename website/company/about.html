About Evershade

A self-hosted AI agent platform for developers who value privacy and control.

Mission: To create a world where anyone can run powerful AI agents on their own hardware, without relying on cloud providers or sacrificing data privacy.

What Is Evershade

Evershade is a collection of specialized microservices that work together to provide a complete AI agent platform. Unlike cloud-based AI tools, Evershade runs entirely on your own hardware — your data never leaves your machine unless you explicitly connect an external AI provider.

The platform is built around the concept of agents — autonomous AI workers that can write code, scrape websites, search knowledge bases, send notifications, and chain tasks together. Each agent is powered by a dedicated microservice, making the system modular, scalable, and easy to extend.

Core Values

🔒

Privacy First

Your data stays on your machine. No telemetry, no analytics, no cloud dependency. You own everything.

🧩

Modular Design

Use only what you need. Each service is independent and can be enabled or disabled based on your requirements.

🔓

Open Source

Licensed under MIT. Fork it, modify it, contribute back. The code is transparent and community-driven.

⚡

Developer Experience

If you can run Docker, you can run Evershade. Simple installation, clear documentation, sensible defaults.

🎯

Real Work

Agents don't just chat — they write code, execute tasks, scrape data, and produce tangible results.

🌍

Self-Hosted

Run on a laptop, a home server, or a cloud VM. You control the infrastructure, the cost, and the uptime.

Naming Theme

All services are named after ghosts from the Luigi's Mansion series. The repository is named Evershade after Evershade Valley from Luigi's Mansion: Dark Moon.
