Roadmap

Version 1.7.0 — Last Updated: 2026-10-22

Phase 1 — Foundations

  • Complete ecosystem audit
  • Architecture documentation
  • Version manifest
  • Standardized configuration (.env.example)
  • Docker Compose profiles and hardening
  • Core documentation (SECURITY, DEPLOYMENT, CONFIGURATION, etc.)

Phase 2 — Security & Persistence

  • Hider: Implement AES-256-GCM encryption for secrets
  • Hider: SQLite persistence for secrets and configs
  • Migrate all services to Bearer token auth
  • Trapper: SSRF protection (private IP blocking, metadata endpoint blocking)
  • Container hardening: read-only filesystem, capability dropping, tmpfs
  • Remove hardcoded localhost references
  • Sneaker: SQLite persistence for metrics, traces, logs
  • Poltergeist: SQLite persistence for notifications
  • Emergency stop implementation in Greenie
  • CSRF protection for web UI sessions
  • Rate limiting on authentication endpoints

Phase 3 — Real Implementation

  • Shrewd: Real LLM provider integration (OpenAI, Anthropic, Google, Ollama)
  • Shrewd: Model routing with cost tracking and privacy classification
  • Poltergeist: Real notification delivery (Slack, Discord, email, Telegram)
  • Poltergeist: SQLite persistence for notifications
  • Slammer: Real dashboard with Greenie API integration
  • Speedy CLI: Full command set (install, start, stop, doctor, logs, backup, restore)
  • Greenie → Gobber migration: Hybrid stores with Gobber-first, local fallback

Phase 4 — Workflow Engine

  • Persistent workflow definitions
  • Workflow triggers (schedule, webhook, file changes)
  • Visual workflow builder in dashboard
  • Approval gates with human-in-the-loop
  • Workflow execution history and audit trail
  • End-to-end workflow integration test

Phase 5 — Agent Workstations

  • Container driver for isolated agent environments
  • Workstation lifecycle management (create, start, stop, destroy)
  • Network policy enforcement (default-deny)
  • Human access: live terminal and desktop via gateway
  • Integration with Slinker and workflow engine

Phase 6 — Quality & Release

  • Ecosystem-wide integration tests
  • Security tests (prompt injection, SSRF, auth bypass)
  • Performance benchmarks and baselines
  • Agent evaluation suite
  • Failure injection tests
  • Release signing and provenance
  • Complete README with tutorial

Phase 7 — UI and Extensibility

  • Resolve Greenie/Slammer relationship (Slammer as single dashboard)
  • Integrate workflow builder
  • Improve operational dashboards (Metrics, Logs pages)
  • Add Workstations live terminal (WebSocket-based)
  • Add MCP and plugin support (MCP server, plugin registry)
  • Ensure every visible control connects to real functionality

Phase 8 — Quality and Release

  • Emergency stop: Global kill switch (pause workflows, cancel jobs, notify)
  • Activity Timeline: Cross-service event history with audit trail
  • WORKSTATIONS.md: Complete workstation documentation
  • Slinker runner interface: Pluggable runner abstraction (Junie default, extensible)
  • Alerting system: Alert rules, deduplication, Poltergeist delivery
  • Credential rotation: API key, encryption key, session secret rotation
  • Final Implementation Report: Complete audit of all 8 phases
  • Documentation: Updated ROADMAP, CHANGELOG, version-manifest, .env.example
