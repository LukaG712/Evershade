Server Mode

# SSH into server
ssh user@server

# Clone and configure
git clone https://github.com/LukaG712/Evershade.git && cd Evershade
cp .env.example .env

# Edit for server mode
sed -i 's/EVERSHADE_MODE=desktop/EVERSHADE_MODE=server/' .env
sed -i 's/EVERSHADE_BIND_ADDRESS=127.0.0.1/EVERSHADE_BIND_ADDRESS=0.0.0.0/' .env

# Generate secure keys
openssl rand -hex 32

# Start
docker compose --profile standard up -d

Proxmox VM Setup

  • ✓ Create KVM VM (not LXC)
  • ✓ Bridged networking on vmbr0
  • ✓ DHCP reservation or static IP
  • ✓ QEMU guest agent enabled
  • ✓ CPU type: host
  • ✓ Disk: 20+ GB, RAM: 8+ GB

Auto-Start

sudo systemctl enable docker

# Optional: systemd service
sudo tee /etc/systemd/system/evershade.service > /dev/null << 'EOF'
[Unit]
Description=Evershade Platform
Requires=docker.service
After=docker.service

[Service]
Type=oneshot
RemainAfterExit=yes
WorkingDirectory=/path/to/Evershade
ExecStart=/usr/local/bin/docker compose --profile standard up -d
ExecStop=/usr/local/bin/docker compose down

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl enable evershade

Firewall

# Allow gateway port from LAN only
sudo iptables -I DOCKER-USER -i eth0 -p tcp --dport 8080 -s 192.168.1.0/24 -j ACCEPT
sudo iptables -I DOCKER-USER -i eth0 -p tcp --dport 8080 -j DROP

Production Checklist

  • ✓ All default API keys replaced with strong random values
  • ✓ TLS enabled (Caddy proxy or external reverse proxy)
  • ✓ Firewall configured – only ports 80/443 exposed
  • ✓ Automated backup schedule configured
  • ✓ Sneaker alerts configured with Poltergeist delivery
  • ✓ Resource limits appropriate for workload
  • ✓ Rate limiting configured for expected traffic
  • ✓ .env file permissions restricted (chmod 600 .env)
