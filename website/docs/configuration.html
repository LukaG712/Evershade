🔧 Configuration Reference

Complete environment variable reference and configuration validation.

On this page

RequiredDeploymentLLM Providers SlinkerTrapperGeneral

Required Variables

VariableDescription
EVERSHADE_GREENIE_API_KEYGreenie API key (generate with openssl rand -hex 32)
EVERSHADE_SLINKER_API_KEYSlinker API key
EVERSHADE_TRAPPER_API_KEYTrapper API key
EVERSHADE_GOBBER_API_KEYGobber API key
EVERSHADE_ENCRYPTION_KEYHider encryption key (AES-256)

Deployment

VariableDefaultDescription
EVERSHADE_MODEdesktopdesktop = loopback, server = all interfaces
EVERSHADE_BIND_ADDRESS127.0.0.1Bind address for host ports
EVERSHADE_PUBLIC_URLhttp://localhost:8080Public base URL for links and CORS

LLM Providers

VariableDefaultDescription
EVERSHADE_OPENAI_API_KEY*(empty)*OpenAI API key
EVERSHADE_ANTHROPIC_API_KEY*(empty)*Anthropic API key
EVERSHADE_GOOGLE_API_KEY*(empty)*Google AI API key
EVERSHADE_OLLAMA_URLhttp://host.docker.internal:11434Ollama API endpoint
EVERSHADE_OLLAMA_MODELgemma4:12bDefault Ollama model

Slinker

VariableDefaultDescription
EVERSHADE_WORKSPACE_PATH./workspaceWorkspace directory path
EVERSHADE_MAX_CONCURRENT_WORKERS1Max concurrent Slinker workers
EVERSHADE_ISOLATION_MODEworktreeworktree, container, workstation
EVERSHADE_JUNIE_BINjunieJunie CLI binary path
EVERSHADE_REFINE_PROMPTfalseRefine prompts via Ollama

Trapper

VariableDefaultDescription
EVERSHADE_SCRAPE_TIMEOUT30000Scrape timeout in ms
EVERSHADE_CRAWL_MAX_DEPTH10Maximum crawl depth
EVERSHADE_CRAWL_MAX_PAGES100Maximum pages per crawl
EVERSHADE_CRAWL_MAX_CONCURRENCY5Concurrent crawl requests
EVERSHADE_BROWSER_HEADLESStrueHeadless browser mode

General

VariableDefaultDescription
EVERSHADE_LOG_LEVELINFODEBUG, INFO, WARNING, ERROR
EVERSHADE_REDIS_PASSWORD*(empty)*Redis password (optional)
EVERSHADE_OBSIDIAN_VAULT_PATH./obsidian-vaultObsidian vault path
Validate: Run evershade config validate to check for missing variables, deprecated names, and default keys in production.
