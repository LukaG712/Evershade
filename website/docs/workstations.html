💻 Workstations

Isolated container environments for agent execution with full lifecycle management.

On this page

OverviewLifecycleAPI TemplatesAccessCleanup

Overview

Workstations are isolated Docker containers that provide a full development environment for agents. Each workstation has its own filesystem, network, and resource limits. They are managed by Greenie and can be accessed via the Slammer dashboard or API.

Workstation Lifecycle

StateDescription
creatingContainer is being initialized
runningContainer is active and accepting tasks
idleContainer is running but not executing tasks
stoppingContainer is shutting down
stoppedContainer is stopped but preserved
removedContainer is deleted

API Endpoints

MethodPathDescription
GET/api/workstationsList workstations
POST/api/workstationsCreate workstation
GET/api/workstations/{id}Get workstation details
POST/api/workstations/{id}/startStart workstation
POST/api/workstations/{id}/stopStop workstation
DELETE/api/workstations/{id}Remove workstation
GET/api/workstations/{id}/logsGet logs
GET/api/workstations/{id}/statsResource usage stats

Workstation Templates

Templates define the base image and configuration for workstations.

{
  "name": "python-dev",
  "image": "python:3.12-slim",
  "env": {
    "PYTHONUNBUFFERED": "1"
  },
  "volumes": [
    { "host": "./workspace", "container": "/workspace" }
  ],
  "resources": {
    "cpu": "2.0",
    "memory": "2G"
  },
  "commands": [
    "pip install -r /workspace/requirements.txt"
  ]
}

Accessing Workstations

Slammer Dashboard

Open the Workstations page in Slammer to view, start, stop, and access terminal sessions.

API

# Create a workstation
curl -X POST http://localhost:8080/api/workstations \
  -H "Authorization: Bearer $EVERSHADE_GREENIE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"template": "python-dev", "name": "my-workspace"}'

# Get logs
curl http://localhost:8080/api/workstations/{id}/logs \
  -H "Authorization: Bearer $EVERSHADE_GREENIE_API_KEY"

Automatic Cleanup

Workstations can be configured to auto-stop and auto-remove after inactivity.

{
  "auto_stop_after_minutes": 30,
  "auto_remove_after_minutes": 60,
  "max_lifetime_hours": 24
}
Note: Workstation data is ephemeral. Persist important files to mounted volumes or use the backup system.
