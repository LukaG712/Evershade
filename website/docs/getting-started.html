📖 Getting Started

Detailed walkthrough for first-time users, from installation to your first agent.

On this page

PrerequisitesInstallConfigureStart First AgentTroubleshooting

Prerequisites

RequirementMinimumRecommended
OSWindows 10/11, macOS 12+, Ubuntu 22.04+Any supported OS
DockerDocker Engine 24+Docker Desktop (latest)
RAM4 GB8+ GB
CPU2 cores4+ cores
Disk10 GB free20+ GB free

Step 1: Install

git clone https://github.com/LukaG712/Evershade.git && cd Evershade

# Install service repositories
./install.sh --profile minimal    # Linux/macOS
# .\install.ps1 -Profile minimal  # Windows

Step 2: Configure

cp .env.example .env

# Generate API keys
openssl rand -hex 32

# Edit .env and replace each "change-me" value

Step 3: Start

./start.sh --profile minimal      # Linux/macOS
# .\start.ps1 -Profile minimal    # Windows

# Check status
curl http://localhost:8080/health
# {"status": "ok", "service": "Greenie", "version": "1.8.0"}

Step 4: Create Your First Agent

curl -X POST http://localhost:8080/api/agents \
  -H "Authorization: Bearer $EVERSHADE_GREENIE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "researcher", "runner": "junie", "guidelines": "Always cite your sources."}'

Troubleshooting

ProblemSolution
Services won't startRun evershade doctor and check docker compose logs
Port already in useFind conflicting process or change port in docker-compose.yml
API key failedVerify grep EVERSHADE_GREENIE_API_KEY .env
Docker out of memorySet Docker Desktop memory to 8 GB+
Reset everythingdocker compose down -v then restart
