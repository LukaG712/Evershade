💥 Slammer

React-based web dashboard – the primary visual interface for platform management.

Port 5173React/TypeScriptTailwind CSSOptional

On this page

OverviewPagesAccess

Overview

Slammer is the single unified dashboard for Evershade. Greenie operates as API-only backend. Deployed behind Caddy reverse proxy in server mode.

Access

Open http://localhost:5173 in your browser. In server mode with proxy, access via https://your-domain.

Note: Slammer requires the full profile: docker compose --profile full up -d
