⚡ Speedy

Command-line interface – terminal-based management via the evershade command.

CLI ToolPython/ClickRichOptional

On this page

OverviewCommands

Overview

Speedy provides terminal-based management of services, agents, tasks, diagnostics, and backups. Built with Python, Click, and Rich for a polished CLI experience.

Commands

CommandDescription
evershade statusCheck service status
evershade agents listList agents
evershade task submitSubmit a task
evershade config showShow configuration
evershade config setSet configuration value
evershade config validateValidate configuration
evershade backup createCreate a backup
evershade backup restoreRestore from backup
evershade doctorRun diagnostics
evershade panicEmergency stop
# Check status
evershade status

# List agents
evershade agents list

# Run diagnostics
evershade doctor

# Create backup
evershade backup create
