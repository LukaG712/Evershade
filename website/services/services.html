All Services

10 specialized microservices, each with a single responsibility. Services are named after ghosts from the Luigi's Mansion series.

Core Services (Required)

These 4 services are always included and form the foundation of the platform.

🟢

Greenie

Central orchestrator & API backend. All requests flow through Greenie, which routes them to the appropriate microservice. Manages agents, sessions, workflows, missions, and workstations.

Port 8080 Python/FastAPI SQLite
🔗

Slinker

Code execution engine. Runs AI agents against codebases in isolated Git worktrees using the Junie CLI. Handles code generation, file modifications, and refactoring.

Port 8000 Python/FastAPI SQLite
🪤

Trapper

Web scraping & crawling service. Uses Playwright for headless browser automation. Supports single-page scraping, deep crawling, site mapping, and structured data extraction.

Port 3000 TypeScript/Fastify Redis
🟤

Gobber

Persistent storage & knowledge graph. Handles SQLite databases, knowledge graphs, Obsidian vault integration, semantic search, webhooks, analytics, feature flags, and RBAC.

Port 8085 Python/FastAPI SQLite

Supporting Services (Optional)

These services extend the platform with additional capabilities. The platform continues to operate without them.

👟

Sneaker

Observability & monitoring. Collects metrics, distributed traces, and logs from all services. Provides alerting with deduplication and OTLP export.

Port 8086 Python/FastAPI SQLite
🙈

Hider

Encrypted secrets management. Encrypts API keys and sensitive data at rest using AES-256-GCM. Provides versioned configuration management.

Port 8087 Python/FastAPI SQLite
👻

Poltergeist

Notification delivery. Sends alerts to Slack, Discord, email, and Telegram with templated messages and async delivery.

Port 8088 Python/FastAPI SQLite
🧠

Shrewd

LLM provider abstraction. Unified interface for OpenAI, Anthropic, Google AI, and Ollama. Handles model routing, cost tracking, and fallback configuration.

Port 8089 Python/FastAPI In-memory

Frontend & Tools

💥

Slammer

React-based web dashboard. The primary visual interface for managing agents, runs, missions, workflows, workstations, metrics, and logs.

Port 5173 React/TypeScript Tailwind CSS
⚡

Speedy

Command-line interface. Provides terminal-based management of services, agents, tasks, diagnostics, and backups via the evershade command.

CLI Tool Python/Click Rich

Service Dependencies

Understanding how services interact with each other.

Service Depends On Used By
Greenie Slinker, Trapper, Gobber (required); Sneaker, Hider, Poltergeist, Shrewd (optional) All services, Slammer, Speedy
Slinker Junie CLI (external), Ollama (optional) Greenie
Trapper Redis (queues), Playwright/Chromium Greenie, Gobber
Gobber Shrewd (optional, for embeddings) Greenie, Slinker
Sneaker Poltergeist (optional, for alert delivery) Greenie (dashboard)
Hider None (leaf service) All services (on demand)
Poltergeist External services (Slack, Discord, SMTP, Telegram) Greenie, Sneaker
Shrewd External LLM APIs (OpenAI, Anthropic, Google, Ollama) Greenie, Slinker, Gobber
Slammer Greenie (all API calls) Users (browser)
Speedy Greenie API, Docker Compose Users (terminal)

Health Endpoints

Every service exposes standard health check endpoints.

Endpoint Method Description
/health GET Liveness check – returns 200 if process is running
/ready GET Readiness check – returns 200 if fully initialized (DB, config, deps)
/api/status GET Detailed status – version, capabilities, dependency health
Optional Services Policy: When an optional service is unavailable, the platform continues to operate. Greenie logs a warning and marks the service as unavailable. Features depending on the unavailable service degrade gracefully – no cascade failure.
