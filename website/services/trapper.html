🪤 Trapper

Web scraping & crawling service using Playwright for headless browser automation.

Port 3000 TypeScript/Fastify Redis Required

On this page

Overview API Endpoints Configuration Security

Overview

Trapper uses Playwright for headless browser automation. Supports single-page scraping, deep crawling, site mapping, structured data extraction, and autonomous browsing agents.

API Endpoints

MethodPathDescription
GET/healthHealth check
POST/api/scrapeScrape a single page
POST/api/crawlStart a crawl job
POST/api/mapMap a website
POST/api/searchSearch the web
POST/api/extractExtract structured data
POST/api/interactBrowser interaction
POST/api/agentAutonomous browsing agent
