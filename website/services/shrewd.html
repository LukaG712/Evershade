🧠 Shrewd

LLM provider abstraction – unified interface for OpenAI, Anthropic, Google AI, and Ollama.

Port 8089Python/FastAPIIn-memoryOptional

On this page

OverviewAPI EndpointsProvidersRouting

Overview

Shrewd provides a unified interface for multiple LLM providers with model routing, cost tracking, and fallback configuration. Supports OpenAI, Anthropic, Google AI, and local Ollama models.

API Endpoints

MethodPathDescription
GET/healthHealth check
POST/api/chatChat completion
GET/api/modelsList available models
GET/api/providersList providers
GET/api/usageToken usage and cost stats

Model Routing

Shrewd supports conditional routing based on request properties:

{
  "routing_rules": [
    {"condition": "cost_sensitive", "provider": "ollama", "model": "gemma4:12b"},
    {"condition": "high_quality", "provider": "openai", "model": "gpt-4o"},
    {"condition": "default", "provider": "anthropic", "model": "claude-sonnet-4-20250514"}
  ]
}

Configure automatic fallback on provider failure:

{
  "primary": {"provider": "openai", "model": "gpt-4o"},
  "fallbacks": [
    {"provider": "anthropic", "model": "claude-sonnet-4-20250514"},
    {"provider": "ollama", "model": "gemma4:12b"}
  ],
  "fallback_on": ["rate_limit", "timeout", "error"]
}
