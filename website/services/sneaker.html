👟 Sneaker

Observability & monitoring – metrics, distributed traces, logs, and alerting with OTLP export.

Port 8086Python/FastAPISQLiteOptional

On this page

OverviewAPI EndpointsOTLP Support

Overview

Sneaker collects and queries metrics, distributed traces, and structured logs from all services. Provides alerting with deduplication and OTLP export for integration with external monitoring systems.

API Endpoints

MethodPathDescription
GET/healthHealth check
POST/api/metricsRecord metric
GET/api/metricsQuery metrics
POST/api/tracesRecord trace span
GET/api/tracesQuery traces
POST/api/logsRecord log entry
GET/api/logsQuery logs
GET/api/alertsList fired alerts
GET/api/alerts/rulesList alert rules
PUT/api/alerts/rules/{id}Update alert rule
POST/api/alerts/{id}/ackAcknowledge alert
GET/api/alerts/statsAlert statistics

OTLP Support

POST/v1/logsReceive OTLP logs

GET/api/otlp/export/logsExport logs in OTLP JSON
