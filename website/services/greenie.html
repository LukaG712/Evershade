🟢 Greenie

Central orchestrator & API backend. All requests flow through Greenie, which routes them to the appropriate microservice.

Port 8080 Python/FastAPI SQLite Required

On this page

Overview Responsibilities Dependencies API Endpoints Authentication Configuration Health Checks

Overview

Greenie is the heart of the Evershade platform. It serves as the central gateway for all API requests, orchestrating communication between services and managing the core platform state. It provides the web dashboard static files, chat API with SSE streaming, workflow engine, and RBAC management.

Responsibilities

  • ✓ Agent definitions and configuration
  • ✓ Chat sessions and conversation history
  • ✓ Workflow definitions and execution state
  • ✓ User accounts and RBAC policies
  • ✓ Approval workflows
  • ✓ Analytics events (delegates storage to Gobber)
  • ✓ Feature flags (delegates storage to Gobber)
  • ✓ Webhook definitions (delegates storage to Gobber)
  • ✓ Mission Control lifecycle management
  • ✓ Workstation management
  • ✓ MCP server integration
  • ✓ Plugin system

Authentication

Greenie supports two authentication methods:

  • ✓ Service-to-service: Bearer token API keys via Authorization: Bearer <key> header
  • ✓ Browser users: Username/password with bcrypt hashing, HMAC-signed session cookies
