🙈 Hider

Encrypted secrets management with AES-256-GCM encryption and versioned configuration.

Port 8087 Python/FastAPI SQLite Optional

On this page

Overview API Endpoints Encryption

Overview

Hider provides encrypted storage and retrieval of secrets and centralized configuration. All secrets are encrypted at rest using AES-256-GCM with a 96-bit random nonce per operation.

API Endpoints

MethodPathDescription
GET/healthHealth check
POST/api/secretsCreate secret
GET/api/secretsList secrets
GET/api/secrets/{key}Get secret
PUT/api/secrets/{key}Update secret
DELETE/api/secrets/{key}Delete secret
POST/api/configsCreate config
GET/api/configsList configs
GET/api/configs/{key}Get config

Encryption

  • ✓ AES-256-GCM authenticated encryption
  • ✓ 96-bit random nonce per operation (no reuse)
  • ✓ Key derived from EVERSHADE_ENCRYPTION_KEY via SHA-256
  • ✓ Secrets never logged or exposed in list responses
  • ✓ SQLite persistence – survives container restarts
Important: Set a strong EVERSHADE_ENCRYPTION_KEY in production. Default key will be blocked in server mode.
