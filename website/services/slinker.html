🔗 Slinker

Code execution engine. Runs AI agents against codebases in isolated Git worktrees using the Junie CLI.

Port 8000 Python/FastAPI SQLite Required

On this page

Overview API Endpoints Configuration Isolation

Overview

Slinker executes AI agent tasks in isolated Git worktrees using the Junie CLI. It handles code generation, file modifications, refactoring, and test execution. Each task runs in its own workspace with explicit repository boundaries.
