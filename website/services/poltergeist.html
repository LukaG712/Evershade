👻 Poltergeist

Notification delivery – Slack, Discord, Email, and Telegram with templating and async delivery.

Port 8088 Python/FastAPI SQLite Optional

On this page

Overview API Endpoints Channels

Overview

Poltergeist sends notifications through multiple channels with templating and async delivery. Supports Slack, Discord, email (SMTP), and Telegram.

API Endpoints

MethodPathDescription
GET/healthHealth check
POST/api/notificationsSend notification
GET/api/notificationsList notifications
POST/api/templatesCreate template
GET/api/templatesList templates
POST/api/templates/{name}/sendSend from template

Supported Channels

  • ✓ Slack – Incoming webhooks and bot tokens
  • ✓ Discord – Webhook URLs
  • ✓ Email – SMTP with TLS support
  • ✓ Telegram – Bot API with chat IDs
  • ✓ Custom – Webhook channels via plugins
