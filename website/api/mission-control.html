🎯 Mission Control

Orchestrated AI missions with milestones, validation, and fix-revalidate cycles.

On this page

OverviewLifecycleMilestones ValidationAPIExample

Overview

Mission Control breaks large tasks into milestones, lets AI plan and execute, then validates automatically with fix-revalidate cycles. It's the primary way to run complex, multi-step AI workflows.

Mission Lifecycle

StateDescription
planningAI is generating the milestone plan
readyPlan complete, awaiting user approval
runningExecuting milestones sequentially
validatingRunning validation checks
fixingFixing failed validation
completedAll milestones passed
failedMax fix attempts exceeded
cancelledUser cancelled

Milestones

Each milestone has a title, description, and optional validation criteria. Milestones execute sequentially – the next milestone starts only after the previous one passes validation.

Validation & Fix-Revalidate

After each milestone, validation checks run. If validation fails, the system automatically attempts to fix the issue and re-validates. This cycle repeats up to max_fix_attempts (default: 3).

API Endpoints

MethodPathDescription
POST/api/missionsCreate mission
GET/api/missionsList missions
GET/api/missions/{id}Get mission details
POST/api/missions/{id}/approveApprove plan
POST/api/missions/{id}/cancelCancel mission
GET/api/missions/{id}/milestonesList milestones
GET/api/missions/{id}/logsGet mission logs

Example: Create a Mission

curl -X POST http://localhost:8080/api/missions \
  -H "Authorization: Bearer $EVERSHADE_GREENIE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Refactor auth module",
    "description": "Refactor the authentication module to use JWT tokens",
    "repository": "my-project",
    "max_fix_attempts": 3,
    "milestones": [
      {"title": "Analyze current auth code", "validation": "summary_generated"},
      {"title": "Implement JWT token handling", "validation": "tests_pass"},
      {"title": "Update API endpoints", "validation": "tests_pass"},
      {"title": "Write documentation", "validation": "docs_exist"}
    ]
  }'
Tip: You can omit the milestones array and let AI generate the plan automatically based on your description.
