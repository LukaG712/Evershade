📡 API Reference

Every API endpoint for every service. All services use HTTP/JSON REST APIs with Bearer token authentication.

Services

GreenieSlinkerTrapper GobberSneakerHider PoltergeistShrewd

Authentication

All endpoints require Authorization: Bearer <api-key> header. Query parameter authentication is not supported.

Standard Response Format

{
  "success": true,
  "data": { ... },
  "error": null,
  "requestId": "uuid",
  "timestamp": "2026-10-22T10:00:00Z"
}
