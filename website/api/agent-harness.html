🤖 Agent Harness

Spec Mode, droids, skills, hooks, and environments for advanced agent development.

On this page

OverviewSpec ModeDroids SkillsHooksEnvironments

Overview

The Agent Harness provides the execution framework for AI agents. It includes Spec Mode for structured task definitions, custom droids for specialized behavior, a skills system for reusable capabilities, event-driven hooks, and isolated environments.

Spec Mode

Spec Mode allows you to define tasks with structured specifications instead of free-form prompts. Specs include input/output schemas, constraints, and validation rules.

{
  "spec": {
    "name": "code_review",
    "input": {
      "type": "object",
      "properties": {
        "file_path": {"type": "string"},
        "language": {"type": "string"}
      }
    },
    "output": {
      "type": "object",
      "properties": {
        "issues": {"type": "array"},
        "suggestions": {"type": "array"}
      }
    },
    "constraints": ["focus_on_security", "ignore_style"]
  }
}

Droids

Droids are specialized agent configurations with predefined capabilities and behavior patterns. Each droid type has its own toolset and execution model.

Droid TypeCapabilities
coderCode generation, refactoring, testing
researcherWeb scraping, knowledge graph search
reviewerCode review, security analysis
deployerBuild, test, deploy workflows

Skills System

Skills are reusable capabilities that agents can use. They are organized in a hierarchical structure with inheritance and composition.

  • ✓ Built-in skills: File operations, code analysis, web scraping
  • ✓ Custom skills: Define your own in skills/ directory
  • ✓ Skills inheritance: Child skills inherit parent capabilities
  • ✓ Skills composition: Combine multiple skills into workflows

Event-Driven Hooks

Hooks allow you to trigger actions at specific points in the agent lifecycle.

HookTrigger
on_task_startBefore task execution begins
on_task_completeAfter task completes successfully
on_task_failAfter task fails
on_tool_callBefore each tool invocation
on_milestone_completeAfter milestone validation passes

Environments

Agents run in isolated environments with controlled access to resources.
