All Services

Evershade consists of 10 independent microservices, each with a single responsibility. All service names are inspired by Luigi's Mansion ghosts.

Greenie — Central Hub & API Backend

Luigi's Mansion origin: Greenie — small green ghosts from Luigi's Mansion: Dark Moon (Evershade Valley).

The brain of the operation. Greenie is a full-featured API server that manages AI agents, chat sessions, pipelines, analytics, and provides a unified view of the entire platform. It operates as an API-only backend.

FeatureDetails
Port8080
API320+ endpoints with Swagger/ReDoc docs
StorageSQLite with feature-store persistence
RoleOrchestrator, agent manager, analytics hub
FeaturesEmergency stop, activity timeline, credential rotation, MCP, plugins, workflow engine, workstations, hybrid stores
→ GitHub: LukaG712/Greenie

Slinker — Execution Engine

Luigi's Mansion origin: Slinker — stealthy ghost enemies from Luigi's Mansion 3 that slink along walls and floors.

The worker behind the scenes. Slinker takes tasks from Greenie and executes them in isolated Git worktrees using the Junie CLI. It handles code generation, file modifications, refactoring, and any task that requires running AI agents against a codebase.

FeatureDetails
Port8000
UIAPI only (no web frontend)
IsolationGit worktrees per task
RunnerJunie CLI integration (pluggable, extensible)
RoleTask execution, code agent runner
→ GitHub: LukaG712/Slinker

Trapper — Web Scraping & Crawling

Luigi's Mansion origin: Trapper — ghost enemies from Luigi's Mansion 3 that trap and capture.

The eyes on the web. Trapper uses Playwright to scrape, crawl, search, and map websites, turning raw HTML into clean, structured, LLM-ready data. It supports single-page scraping, deep crawling, site mapping, and background job queues via Redis.

FeatureDetails
Port3000
UIAPI only (no web frontend)
BrowserPlaywright headless
QueueRedis-backed job queue
RoleWeb scraping, crawling, content extraction
→ GitHub: LukaG712/Trapper

Gobber — Persistent Storage & Knowledge Graph

Luigi's Mansion origin: Gobber — blob-like ghosts from Luigi's Mansion: Dark Moon that absorb and store everything.

The memory and brain of the ecosystem. Gobber provides persistent storage for webhooks, analytics, RBAC, cache, and feature flags — solving the in-memory data loss problem when services restart. It also integrates Obsidian vault as a second brain — scanning your notes, generating embeddings, and enabling semantic search.

FeatureDetails
Port8085
StorageSQLite with WAL mode
FeaturesWebhooks, analytics, RBAC, cache, feature flags, knowledge graph
ObsidianVault scanning, semantic search, graph traversal
RoleCentralized data layer & semantic memory
→ GitHub: LukaG712/Gobber

Sneaker — Observability

Luigi's Mansion origin: Sneaker — quiet ghosts from Luigi's Mansion: Dark Moon that sneak up silently.

The eyes on your system. Sneaker collects metrics, traces, and logs from all services, providing unified observability. Includes an alerting system with deduplication, cooldown, and Poltergeist delivery.

FeatureDetails
Port8086
FeaturesMetrics, distributed traces, log aggregation, alerting
RoleSystem health monitoring
→ GitHub: LukaG712/Sneaker

Hider — Secrets & Config

Luigi's Mansion origin: Hider — ghosts from Luigi's Mansion: Dark Moon that hide in plain sight.

The vault for sensitive data. Hider provides encrypted storage for API keys, passwords, and centralized configuration management using AES-256-GCM encryption with SQLite persistence.

FeatureDetails
Port8087
EncryptionAES-256-GCM
StorageSQLite
FeaturesEncrypted secrets, versioned config
RoleSecret and configuration management
→ GitHub: LukaG712/Hider

Poltergeist — Notifications

Luigi's Mansion origin: Poltergeist — the ancient ghosts from Luigi's Mansion: Dark Moon that cause disturbances and ruckuses.

The messenger of the ecosystem. Poltergeist sends notifications to Slack, Discord, email, and Telegram with templated messages and async delivery. Includes SQLite persistence for notification history.

FeatureDetails
Port8088
ChannelsSlack, Discord, email, Telegram, webhooks
StorageSQLite persistence
RoleUnified notification hub
→ GitHub: LukaG712/Poltergeist

Shrewd — LLM Abstraction

Luigi's Mansion origin: Shrewd — one of the Three Sisters (Possessors) from Luigi's Mansion: Dark Moon, known for being cunning and intelligent.

The brain behind the models. Shrewd provides a unified interface for OpenAI, Anthropic, Google, and Ollama — letting you swap models and manage costs with privacy classification.

FeatureDetails
Port8089
ProvidersOpenAI, Anthropic, Google, Ollama
FeaturesModel routing, cost tracking, privacy classification
RoleLLM provider abstraction
→ GitHub: LukaG712/Shrewd

Slammer — Web Dashboard

Luigi's Mansion origin: Slammer — blue ghosts from Luigi's Mansion: Dark Moon that slam the ground with force.

The command center. Slammer is a React-based standalone web dashboard for managing agents, runs, pipelines, and analytics across all Evershade services. It is the single unified dashboard — Greenie operates as API-only backend.

FeatureDetails
Port5173
StackReact, TypeScript, Tailwind CSS
FeaturesServices, agents, runs, workflows, workstations, metrics, logs, plugins/MCP management
RoleStandalone web dashboard
→ GitHub: LukaG712/Slammer

Speedy — CLI Tool

Luigi's Mansion origin: Speedy Spirit — fast ghosts from Luigi's Mansion that zoom around at high speed.

The terminal companion. Speedy provides an evershade command for managing services, agents, tasks, and configuration from the command line.

FeatureDetails
Installpip install speedy-cli
Commandevershade
FeaturesInstall, start, stop, logs, doctor, backup/restore
RoleCommand-line interface
→ GitHub: LukaG712/Speedy
